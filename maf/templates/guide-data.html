curl

Save your token once, then call any endpoint:

export MAF_TOKEN="<your token>"

# The latest four days of posts
curl -H "Authorization: Bearer $MAF_TOKEN" \
  "{{ base_url }}/api/v1/posts"

# Most viewed, in the four days before a date
curl -H "Authorization: Bearer $MAF_TOKEN" \
  "{{ base_url }}/api/v1/posts?sort=views&before=2026-11-20"

# Every hashtag with its post count
curl -H "Authorization: Bearer $MAF_TOKEN" \
  "{{ base_url }}/api/v1/tags"

# One thread with its comments
curl -H "Authorization: Bearer $MAF_TOKEN" \
  "{{ base_url }}/api/v1/threads/THREAD_ID"

# Search posts and comments
curl -H "Authorization: Bearer $MAF_TOKEN" \
  "{{ base_url }}/api/v1/search?q=berlin"

From a script

Send the same header from any language, for example Python:

import os, urllib.request
request = urllib.request.Request(
    "{{ base_url }}/api/v1/posts",
    headers={"Authorization": f"Bearer {os.environ['MAF_TOKEN']}"},
)
print(urllib.request.urlopen(request).read().decode())

MCP server

For Claude Code, Cursor or any MCP client. You need uv installed; add this to your client's MCP settings with your token:

{
  "mcpServers": {
    "maf": {
      "command": "uv",
      "args": [
        "run",
        "https://raw.githubusercontent.com/SomeoneElseSt/MAF/main/maf/mcp.py"
      ],
      "env": {
        "MAF_TOKEN": "<your token>",
        "MAF_URL": "{{ base_url }}"
      }
    }
  }
}

It offers three tools: list_posts, get_thread and search.
