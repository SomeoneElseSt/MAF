MCP server

For Claude Code, Cursor or any MCP client, run maf-mcp from this project with your token:

{
  "mcpServers": {
    "maf": {
      "command": "maf-mcp",
      "env": { "MAF_TOKEN": "<your token>", "MAF_URL": "{{ base_url }}" }
    }
  }
}

It offers three tools: list_posts, get_thread and search.

curl

curl -H "Authorization: Bearer $MAF_TOKEN" {{ base_url }}/api/v1/posts
curl -H "Authorization: Bearer $MAF_TOKEN" "{{ base_url }}/api/v1/posts?sort=views&before=2026-11-20"
curl -H "Authorization: Bearer $MAF_TOKEN" {{ base_url }}/api/v1/tags
curl -H "Authorization: Bearer $MAF_TOKEN" {{ base_url }}/api/v1/threads/THREAD_ID
curl -H "Authorization: Bearer $MAF_TOKEN" "{{ base_url }}/api/v1/search?q=berlin&page=1"

From a script

Send the same header from any language, for example Python:

import os, urllib.request
request = urllib.request.Request(
    "{{ base_url }}/api/v1/posts",
    headers={"Authorization": f"Bearer {os.environ['MAF_TOKEN']}"},
)
print(urllib.request.urlopen(request).read().decode())

Anything you read this way leaves the students-only site, for example into an AI provider's systems. Copying and pasting already did that, so a token adds convenience rather than a new hole.
