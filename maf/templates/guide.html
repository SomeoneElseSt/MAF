User Guide

Anonymity

You get a random name in each thread to avoid traceability across posts. Your email is never stored and only used for verification using blind signatures.

Rules

Don't name students or staff. Be respectful. Five flags on a post hide it. A hidden post can be restored or deleted permanently on a case-by-case basis.

Making a post

Click Submit and add a title plus a link or some text; hashtags are optional. Posts can't be edited afterwards.

Private replies

Tick "Make only visible to …" under a comment box to reply to just that person. Your browser encrypts the reply before sending it, so MAF's server only stores scrambled text it can't read. Private replies only appear on the device you were signed in on when you made them, and they need JavaScript.

One limit: MAF's server also sends the page's code, so someone in control of the server could change that code to copy replies before they're encrypted. Encryption protects against anyone reading the stored database or its backups.

Hashtags

#help, #wondering, #confession and #hottakes suggest a template for your post and its replies. #hottakes posts are highlighted in orange on the main page.

Developers may choose to read MAF programmatically.
